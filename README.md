# Maincrafts Technology – Python Programming Internship | Task 1

## Core Python Challenges

This repository contains my solution for **Task 1** of the **Maincrafts Technology Python Programming Internship**.

The task focuses on building a strong foundation in **Core Python** through practical programming challenges involving variables, operators, conditional statements, loops, functions, strings, and number manipulation.

## Challenges Completed

The following 8 Python programming challenges have been implemented:

1. **Sum of Two Numbers** – Take two numbers as input and calculate their sum.
2. **Odd or Even Checker** – Determine whether a given number is odd or even.
3. **Factorial Calculation** – Calculate the factorial of a number using a loop.
4. **Fibonacci Sequence** – Generate the first `n` numbers of the Fibonacci sequence.
5. **String Reverse** – Reverse a user-provided string.
6. **Palindrome Check** – Check whether a word reads the same forward and backward.
7. **Leap Year Check** – Determine whether a given year is a leap year.
8. **Armstrong Number** – Check whether a number is an Armstrong number.
